# Private Memo 功能宣传片 v2：自然语音版

更新时间：2026-10-16。

本版保留 v1 的 106 秒时间轴、1080p 画面、真机录屏、章节布局和原创 BGM，重新制作全部解说与字幕。

## 文件

- `private-memo-promo-v2.mp4`：完整宣传片，1920 × 1080、30 fps、H.264 + 48 kHz AAC。
- `opening-preview.m4a`：前 18 秒纯旁白试听，不含 BGM。
- `narration.zh-CN.m4a`：完整中文旁白，不含 BGM。
- `private-memo-promo-v2.zh-CN.srt`：独立简体中文字幕；成片同时含可见字幕。
- `旁白与分镜.txt`：新版旁白文案及章节时间。
- `audio-normalization.json`：旁白双遍响度归一化的第一遍测量数据。

## 声音改动

- 将 v1 的 macOS Tingting 系统合成语音替换为 Microsoft 中文神经语音 `zh-CN-YunxiNeural`，采用沉稳的品牌说明男声。仍为 AI 合成旁白。
- 改写为更适合口语解说的短句；片头去掉中英文品牌混读。绝大部分语音保持原始自然语速，加密章节仅做约 3% 的时长适配。
- 使用服务返回的句子时间点同步字幕，避免字幕叠字；字幕和画面时间轴均保持 106 秒。
- 统一所有音频中间文件为 48 kHz 双声道 PCM，重新生成连续的音频时间戳。
- 完整混音先写成连续 PCM 母带，再单独编码 AAC，最后与带字幕视频合并，避免原版多输入实时滤镜链与封装过程产生异常音频包时长。
- 旁白采用双遍、线性响度归一化，目标 -16 LUFS、真峰值 -2 dBTP；背景音乐保持稳定的较低音量，去掉旧版逐段侧链压缩，减少明显的音量起伏。

逐包复核发现原版 `pts=6.997333` 的 AAC 包时长异常，为 `3.702854` 秒，而正常 48 kHz AAC 包应约为 `0.021333` 秒；另有一包为 `0.102500` 秒。时间戳连续并不代表每包时长正常，这种异常长包可能使播放器出现明显停顿。v2 对整条音轨按固定时长重新编码，并逐包验证；旧语音的合成质感和中英文混读节奏也通过替换声音与改写文案处理。

配音合成仅发送本片公开宣传文案，未发送手机录音、钱包数据或配对凭据。画面中的功能演示边界沿用 [v1 制作说明](../private-memo-promo-v1/README.md)：实机转写为 Paraformer，摘要为本地 Qwen3-0.6B；钱包章节展示二维码与恢复入口，未执行真实签名或广播交易。

制作脚本：工作区 `.tmp/memo-promo/natural_v2.py`；神经语音原片与逐句时间数据在 `.tmp/memo-promo/natural-v2/`。
