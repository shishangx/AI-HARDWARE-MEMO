## 拍摄与演示边界

操作画面由连接的 Solana Mobile Seeker 真机通过 ADB `screenrecord` 录制。手机在飞行模式下完成 Paraformer 转写与本地 Qwen3-0.6B 摘要。转写和摘要输入为两段专门合成的中文演示语音，未使用原有私人录音。

拍摄前临时保留原有录音、转写和摘要目录；拍摄后已恢复到原有 8 条录音、10 条转写、2 份摘要。演示数据单独留在手机 `promo-preserved-20261016/demo-*` 目录，原有模型、钱包配对和联网设置保留。

视频中的推理等待和操作间隔经过剪辑，并在画面注明。模型列表用于介绍支持范围，本片实际执行的 ASR 为 Paraformer。每日摘要为实测模型输出，可能存在遗漏，画面注明以来源原文为准。重命名展示编辑入口；单条与批量删除为功能介绍，本片未执行删除。

二维码镜头是设备端实际生成的演示转写密文二维码与恢复入口二维码。链上网络为 Base Sepolia；本次录制未请求钱包签名、未广播交易，也未展示或导出配对密钥材料。钱包端签名、广播和最终恢复结果不属于本片实录范围。

制作中间文件与录屏原片位于工作区 `.tmp/memo-promo/`，其中 `capture.py` 为拍摄脚本，`produce.py` 为编排、字幕、旁白、原创 BGM 与 FFmpeg 合成脚本。
